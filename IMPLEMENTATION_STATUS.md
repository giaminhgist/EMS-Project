## Approved deviations from the guide

1. **No `All_Data.xlsx` exists** in this dataset release; the audited
   population is the 160-workbook inventory (`source_inventory.json`), and
   labels come from the dataset README rule (<200 → HC, ≥200 → SZ) — approved
   in Phase 0 (Decision 7).
2. **Zero-spatial trials policy** (Decision 8): the 5 trials with no usable
   spatial fixation are recorded in `trial_manifest` with
   `qc_status="excluded_no_spatial_fixations"` and no heatmap row.
3. **Package name** `src/stage1` (not `src/Stage-1`) — Decision 1.
4. **CPU-only execution**: no GPU/CUDA on this machine; all extraction and
   training ran on CPU (Decisions 2/3 context).
5. **`median_fixation_duration_ms`** added to `trial_qc.parquet` (Phase-2
   EDA requirement); heatmap arrays unchanged.
6. **`--stimulus-limit` / `--subjects`** require an output-root override so
   partial runs can never masquerade as canonical artifacts.
7. **Best-checkpoint eligibility** defined as
   `epoch >= norm_start_epoch + norm_ramp_epochs` (0-based).
8. **Ablation overlays** live as delta files under
   `configs/stage1/ablations/` merged onto `base.yaml` (one primary factor
   each); the resolved full config is saved with every run.
9. **CV partition files include excluded-status trials as observed rows**;
   Stage 1 filters them at the dataset boundary (2 rows in fold 0's train
   partition).
10. **Between-stimulus dispersion floor added to the Stage-1 normative
    loss** (user-approved, 2026-08-31): `loo_cosine_normative_loss`
    additionally returns `spread_loss = mean_{i≠j} max(0, d_floor −
    (1 − cos(c_i, c_j)))²` over normalized stimulus centroids (0 when fewer
    than 2 groups), weighted by `lambda_spread` (default 5.0; 0.5 too weak
    on the verification runs) on the
    `lambda_norm` ramp schedule. Total loss = recon + λ_N·norm +
    λ_spread·spread. Motivated by collapse of all 100 centroids to pairwise
    cosine similarity ≈ 0.9998 in the 2026-08-31 base run (`history.csv`,
    `best_val_embeddings.npz`). Amends guide §10.2; the "No
    VICReg/InfoNCE/SupCon" clause is unchanged — the hinge is a centroid
    dispersion regularizer, not a contrastive objective.

## Unresolved limitations

- **Compute**: 2-core CPU, no GPU. Full 100-epoch × 5-fold training is
  impractical locally (~15 s/epoch × 100 × 5 ≈ 21 h at smoke batch scale;
  full batches are larger). Smoke-scale verification is complete; full
  experiments require GPU/cloud resources.
- **DINO hub revision unpinned**: `facebookresearch/dino:main` via torch.hub
  does not pin a git commit (recorded honestly in `model_metadata.json`;
  checkpoint itself is SHA-256-pinned).
- **Pupil units** unknown; `FIX_PUPIL` is retained in QC only.
- **No early stopping enforcement**: `early_stopping_patience` is configured
  but the base run trains the full epoch budget.
- **No formatter/linter/type checker** configured in the project.
- Viewing duration is right-censored; temporal progression is a reconstructed
  clock (no timestamps in the raw data).
